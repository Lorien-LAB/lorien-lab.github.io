# Site i18n Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the main public portfolio surfaces switch cleanly between English and Chinese without touching Knowledge content or changing Astro Content Collection schemas.

**Architecture:** Keep English Markdown as source-of-truth. Static page copy uses paired `.lang-en` / `.lang-zh` nodes; collection-driven cards read Chinese presentation overrides from `src/data/i18n/publicContentZh.ts` keyed by entry id. The existing `html[data-lang]` visibility layer remains the only runtime mechanism.

**Tech Stack:** Astro 5, TypeScript, static Content Collections, browser `localStorage`, Node test runner.

## Global Constraints
- Branch: `chatgpt/i18n-zh-en-2026-08-16` only.
- Never modify `src/content/knowledge/**`, `src/pages/knowledge/**`, or `src/content.config.ts`.
- Preserve current canonical URLs.
- English is default and source-of-truth.
- No `/en/` or `/zh/` route duplication.
- Run `npm run test`, `npm run check`, and `npm run build` before completion.
