# Site Chinese-English Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent, accessible English/Chinese switch to Lorien Lab without touching Knowledge content files.

**Architecture:** Keep the existing Astro routes and render both localized UI strings in shared components. `BaseLayout` owns the persisted `html[data-lang]` state, while global CSS shows one language at a time and `LanguageToggle.astro` updates the state.

**Tech Stack:** Astro 5, TypeScript, browser `localStorage`, Node built-in test runner, GitHub Actions.

## Global Constraints

- Work only on `chatgpt/i18n-zh-en-2026-08-16`.
- Do not modify `src/content/knowledge/**`.
- Default locale is `en`; accepted locales are exactly `en` and `zh`.
- Persist the selection as `site-language`.
- Keep existing routes and GitHub Pages deployment unchanged.
